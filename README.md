# دفتر التمرين — خطوات النشر على GitHub Pages

## الملفات
```
index.html                 التطبيق كامل
manifest.webmanifest       بيانات التثبيت
sw.js                      يشغّل التطبيق بدون إنترنت
icon-192.png               أيقونة
icon-512.png               أيقونة
icon-maskable-512.png      أيقونة أندرويد المقصوصة
apple-touch-icon.png       أيقونة آيفون
README.md                  هذا الملف
```
> ملاحظة: لا تعيد تسمية `index.html` — الاسم مطلوب ليفتح الموقع مباشرة.

## النشر (خمس دقائق)

1. افتح github.com وسجّل دخول، ثم **New repository**.
2. سمِّه مثلاً `gym` واختر **Public** ثم **Create repository**.
   - المستودع لازم يكون Public لأن GitHub Pages لا يعمل مع الخاص في الحساب المجاني.
3. في صفحة المستودع اضغط **Add file → Upload files**، واسحب **كل** الملفات أعلاه (بدون مجلد يحيط بها)، ثم **Commit changes**.
4. اذهب إلى **Settings → Pages**.
5. تحت **Source** اختر **Deploy from a branch**، وتحت **Branch** اختر `main` والمجلد `/ (root)`، ثم **Save**.
6. انتظر دقيقة أو دقيقتين وحدّث الصفحة، بيظهر لك الرابط:
   `https://اسم-حسابك.github.io/gym/`

## التثبيت على الجوال

**أندرويد (Chrome):** افتح الرابط ← قائمة النقاط الثلاث ← *تثبيت التطبيق* / *إضافة إلى الشاشة الرئيسية*.
قد يظهر لك زر تثبيت داخل تبويب الإعدادات في التطبيق نفسه.

**آيفون (Safari — لازم Safari تحديداً):** افتح الرابط ← زر المشاركة ← *إضافة إلى الشاشة الرئيسية*.

## للأقارب
أرسل لهم نفس الرابط. بيانات كل شخص تُحفظ على جهازه وحده ولا يشوفها غيره،
ولا تُرفع إلى أي خادم — GitHub يستضيف ملفات التطبيق فقط.

## مشاركة مقطع من يوتيوب (أندرويد بعد التثبيت)
داخل تطبيق يوتيوب: مشاركة ← اختر *دفتر التمرين*.
بينفتح التطبيق على وضع التركيز ويشغّل المقطع مباشرة.
(هذه الميزة غير متاحة على آيفون — استخدم زر «لصق رابط منسوخ».)

## التحديث لاحقاً
ارفع `index.html` الجديد بنفس الطريقة، وغيّر رقم النسخة في أول سطر من `sw.js`
(`gymlog-v3` ← `gymlog-v4`) حتى تصل النسخة الجديدة لكل الأجهزة فوراً.

> النسخة الحالية `gymlog-v3` — فيها مجموعات التسخين، وتسجيل الجهد (RPE)،
> وفلترة التمارين على الأجهزة المتوفرة. الثلاثة تُشغَّل من تبويب الإعدادات.

## لو ظهر «الخطأ ١٥٣» مكان مقطع يوتيوب

معناه إنك فاتح `index.html` مباشرة من جهازك. يوتيوب يرفض تشغيل المقطع داخل صفحة
بلا رابط موقع. ارفع الملفات على GitHub Pages وافتح الرابط، وبيشتغل المشغّل داخل
شاشة التركيز عادي. وإلى ذلك يظهر لك زر يفتح المقطع في يوتيوب مباشرة.

## تنبيه
بيانات التطبيق مرتبطة برابط الموقع وبمتصفح الجهاز. لو غيّرت الرابط أو مسحت
بيانات المتصفح، السجل يروح — استخدم زر التصدير في الإعدادات بين فترة وأخرى.
